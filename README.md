# QwizAI - Your Smart AI Quiz Assistant

An intelligent AI-powered application that helps you solve quizzes, MCQs, and analyze images for problem-solving. Built with React, TypeScript, and Google's Gemini AI.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
